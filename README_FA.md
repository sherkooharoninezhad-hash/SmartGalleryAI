# Smart Gallery AI — نسخه اولیه

اپلیکیشن اندروید برای جست‌وجوی تصاویر داخل حافظه گوشی با مدل تشخیص تصویر روی دستگاه.

## امکانات نسخه ۱
- فهرست‌کردن عکس‌های قابل‌دسترسی از طریق MediaStore
- تشخیص برچسب‌های تصویری با ML Kit و مدل همراه برنامه (بدون نیاز به دانلود مدل در اجرای اول)
- جست‌وجوی متنی با چند واژه فارسی نمونه مانند چوب، درخت، ماشین، گربه، سگ، کوه، دریا، گل و غذا
- انتخاب عکس نمونه و رتبه‌بندی عکس‌ها با ترکیب شباهت برچسب‌ها و هش تصویری
- نمایش نتایج و درصد شباهت و بازکردن عکس انتخابی

## ساخت APK با GitHub Actions
1. یک مخزن جدید در GitHub بساز.
2. همه محتویات این پوشه را در مخزن قرار بده و با نام `main` ذخیره کن.
3. از تب **Actions** گردش‌کار **Build Smart Gallery AI APK** را انتخاب کن.
4. روی **Run workflow** بزن.
5. پس از پایان موفق، در همان اجرای Workflow بخش **Artifacts** فایل `SmartGalleryAI-debug-apk` را دانلود کن؛ داخل آن `app-debug.apk` است.
6. APK را به گوشی منتقل و نصب کن. اگر اندروید اجازه خواست، نصب از همان منبع را مجاز کن.

## نکات مهم
- برای اسکن کامل، هنگام درخواست مجوز باید دسترسی کامل عکس‌ها را انتخاب کنی؛ در حالت انتخاب محدود، فقط عکس‌های مجاز اندروید دیده می‌شوند.
- جست‌وجوی آفلاین با مدل همراه APK انجام می‌شود. اولین اسکن ممکن است بسته به تعداد عکس‌ها زمان ببرد.
- گزینه آنلاین در رابط فعلی صرفاً حالت انتخابی/آماده‌سازی است و هنوز به سرویس ابری وصل نشده؛ اتصال واقعی آنلاین نیازمند تعیین سرویس و کلید API است. در نسخه فعلی هیچ تصویری به سرور ارسال نمی‌شود.
- این نسخه MVP است؛ مدل عمومی ML Kit همه مفهوم‌ها را با دقت یکسان تشخیص نمی‌دهد. جست‌وجوی دقیق‌ترِ بافت و مفهوم به مدل embedding تصویری مثل CLIP/MobileCLIP و نمایه‌سازی پس‌زمینه نیاز دارد.
